# 28 - ネットワーク7層4択クイズ

**ビルド日**: 2026-11-03
**カテゴリ**: practical
**slug**: seven-layer-network-quiz

## 概要
OSI参照モデルの7層について、層番号・プロトコル・機能を問う30問4択クイズ。各問に解説付きで体系的に学習できる。

## 機能
- 30問の問題バンク（層番号・プロトコル・機器・責務・ポート番号を網羅）
- 4択クイズ形式、回答後に解説を表示
- 正解/総問数/正答率のリアルタイム表示
- ハイスコアをlocalStorageに保存
- 7層早見表を折りたたみで常時参照可能
- 問題はランダムシャッフルで毎回異なる順番
